## 4. 当前资源规格与后续高清工作

本轮将 60 张编辑图片处理为高分辨率 JPEG 并上传到 CloudBase `editorial/`：成对案例图按 768×1024 px 输出、JPEG 质量 86；单张素材最长边最高 1600 px、质量 86；首页主视觉保留 1448×1086 px、质量 88。资源总计约 10.97 MiB。案例卡片和详情使用同一批高清参考图 / 花束图，不再把 300×400 缩略图放大。素材存储桶维持私有读写，`flowerBackend` 只为固定白名单中的案例图片签发 1 小时临时链接；小程序本地缓存链接最多 55 分钟，到期后自动刷新。花材小图最长边仍为 192×288 px，它们只在小尺寸花材清单中使用。

AI 生成与场景合成仍从高清案例链接下载原图到临时文件，再经现有用户素材流程上传；不会把临时签名 URL 当作永久地址保存。AI Worker 当前输出规格为 1024×1024，输入清晰度不会改变模型输出规格。
