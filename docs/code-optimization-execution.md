- 补充电影海报、音乐专辑两张封面素材，旅行案例使用花园素材。微信手机预览上传白名单不包含 WebP，已把小程序引用的 12 张页面图与 49 张花材图改为 JPEG，并在历史作品读取时迁移旧资源路径。
- 首页三张案例图统一固定尺寸；底栏改为统一线性图标；上传卡片使用相册图标并加高；返回按钮贴近屏幕左边；场景模板四等分，花束缩放下限为原始基准的 40%（最多缩小 60%）。
- 灵感详情改为“生成清单 / 保存到作品集”；作品清单记录合并到对应花作而不单独占卡，详情提供原图放大、100 字备注、清单导出和下载图片；花历继续复用同一详情页。
- 底栏改为全屏通栏，三个入口等宽居中，图标统一为房子、两颗空心星和带书脊的画册线稿。作品日历删除“接下来的日子”区块；作品页只显示“今日剩余次数”和当前数字，并移除长按提示文案。
- 作品集与花历共享同一批可见花作：作品保存/删除、日期切换和从花历打开详情都保持关联；旧的独立清单记录不会只出现在花历中。
- 上传完成回调核对登记路径；识花响应和保存清单增加字段、数量范围、单位、图片路径和颜色校验。AI 估算仍为“待确认”，由用户修改后再保存。
- AI 任务按用户和幂等键生成稳定 ID，并检查同一个幂等键是否被复用于不同输入。worker 增加租约 claim token，避免已过期 worker 覆盖新结果或重复结算次数。
- 作品清单支持偏移分页，图片 URL 分批读取；删除记录作为 tombstone 同步至其他设备；未同步作品可按来源键补偿删除。
- 保存、重命名、清单修改会报告本机/云端状态；失败保留待同步标记。花历日期和作品支持跨设备关联；任务恢复时重新读取源图、成品图及素材。
- 场景融合已改为分别上传房间图和花束图，由 `flowerBackend.compose-scene-reference` 校验素材归属并按编辑器位置、缩放和画布比例生成单张私有垫图；任务与作品记录房间图、花束图和合成图关联。flowerBackend 增加 Sharp 依赖。
- 账号清理覆盖作品、日期、任务、额度账本、文件引用、事件、订阅和通知数据。
